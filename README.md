# Submission Reminder App

This is a simple Bash-based app designed to help you stay on top of important deadlines. The app allows users to input deadlines and receive reminders through terminal notifications. It’s lightweight, easy to use, and perfect for managing tasks in a command-line environment. Set up quick reminders and never miss a submission again!

## Features
- Set custom deadlines
- Terminal notifications
- Easy to use with minimal setup
